# nibyblog.pl

Pliki strony znajdują się w `public_html/`. Przy wdrażaniu ustaw ten katalog jako katalog główny witryny lub prześlij jego zawartość na hosting.

Statyczne archiwum HTTrack. Zachowano zapisane strony i zależności lokalne z oryginalnym układem ścieżek, w tym załączniki wskazane przez wpisy. Pominięto cache i logi HTTrack, cookies, konfigurację, pliki PHP i odpowiedzi API dawnego WordPressa oraz nieużywane pliki. Nie wymaga PHP ani bazy danych. Formularze, wyszukiwarka i inne funkcje dawnego WordPressa nie działają jako usługi w archiwum statycznym; brakujące już w źródle zasoby zewnętrzne nie są odtwarzane.
